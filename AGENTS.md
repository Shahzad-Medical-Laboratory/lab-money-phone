# Project: Lab Money Tracker, phone page
- UI and the listed features only. Do not propose or add anything else. Do not ask the owner design questions.
- Plain HTML, CSS, JS. No framework, no build step. Static files that can be hosted on GitHub Pages.
- No secrets in this project. Only the Supabase project URL and the public (publishable) key may appear, in config.js. Never an admin, service role, or secret key. Never a password, never in any file.

- The app is multi-user (anyone can sign up with email), every row is owned by its user_id, and rules about "one owner user" no longer apply.
